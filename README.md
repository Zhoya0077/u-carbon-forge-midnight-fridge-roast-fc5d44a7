A one-line roast of a smart fridge that locks itself at midnight — told as if the leftover pizza hired a bouncer and the hungry owner didn't make the list. One premise, one twist, no wasted words.

**Entry:** "My smart fridge locks at midnight, so the leftover pizza has a bouncer and I'm not on the list."

## Run it

```bash
MAKEFUN_OUTPUT_DIR=/output npx tsx main.ts
# or with plain node after stripping types:
node --experimental-strip-types main.ts
```

It writes `entry.txt` (one line, under 200 characters) into the output directory and refuses to write anything that breaks the gate: wrong length, blank, multi-line, or padded with whitespace.
